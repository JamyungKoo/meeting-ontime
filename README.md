# meeting-ontime

Google Meet 미팅에 늦지 않게 해주는 로컬 도구.
등록해둔 미팅을 **시작 1분 전에, 평소 쓰는 실제 Chrome 창으로, 카메라/마이크가
꺼진 상태로** 자동 참여시켜줍니다. 미팅이 시작되면 그 창에서 마이크만 켜면 됩니다.

- 반복 미팅은 **한 번 등록하면 끝** — 매일 캘린더에서 그날의 시간을 읽어와 자동 참여
- 특정 날짜의 회차만 **건너뛰기**, 휴가 기간은 **날짜 범위로 전체 중지**
- 관리는 로컬 웹페이지(`http://localhost:5959`)에서 클릭으로

## 작동 방식

```
Google Calendar ──(iCal 비공개 주소, 매일+업무시간 1시간마다 동기화)──▶ 로컬 서버(Node)
                                                                       │
                                          시작 1분 전, 실제 Chrome으로 Meet 링크 열기
                                                                       ▼
Chrome 확장(extension/) ──(?ontime=1 탭에서만)──▶ 카메라/마이크 OFF → 자동 참여
```

1. **캘린더 조회** — Google Calendar의 iCal 비공개 주소(`ICS_URL`)를 HTTP로 읽습니다.
   브라우저 자동화도, 로그인 저장도 필요 없습니다. 반복 일정(RRULE)은 자동 전개됩니다.
   동기화 주기: 서버 시작 시 / 매일 자정 / 로컬 시간 08~13시에는 1시간마다 / 수동 새로고침.
2. **미팅 열기** — 로컬 서버가 시각을 감시하다가 시작 `LEAD_SECONDS`(기본 60초) 전에
   `open -a "Google Chrome" <meet-url>?ontime=1` 로 **평소 쓰는 Chrome**에서 엽니다.
   로그인 상태 그대로라 별도 인증이 없습니다.
3. **카메라/마이크 끄기 + 참여** — 함께 제공되는 Chrome 확장이 `?ontime=1`이 붙은
   탭에서만 동작해 토글을 끄고 참여 버튼을 누릅니다. 직접 연 Meet 탭에는 영향이 없습니다.
4. **상태 관리** — 등록/건너뛰기/휴가는 `rules.json`, 접속 이력은 `state.json`에 저장되어
   재시작해도 유지되고 중복 접속하지 않습니다.

## 🤖 AI로 셋업하기 (권장)

이 폴더에서 [Claude Code](https://claude.com/claude-code) 또는 Codex CLI를 실행하고
아래를 붙여넣으세요:

```
이 프로젝트(meeting-ontime)를 셋업해줘.
1. npm install 실행
2. .env.example을 복사해 .env를 만들고, 내가 Google Calendar의 "iCal 형식의
   비공개 주소"를 발급받도록 단계별로 안내해줘 (설정 → 내 캘린더 → 캘린더 통합).
   내가 주소를 주면 ICS_URL에 넣고, 실제로 오늘 미팅이 파싱되는지 테스트해줘.
3. Chrome 확장 설치를 안내해줘 (chrome://extensions → 개발자 모드 →
   압축해제된 확장 프로그램 로드 → 이 프로젝트의 extension/ 폴더).
4. npm start로 실행하고 관리 페이지가 뜨는지 확인해줘.
5. 관리 페이지에서 "지금 접속"으로 실제 Chrome에 Meet이 열리고
   카메라/마이크가 꺼지는지 함께 검증해줘.
```

## 수동 셋업

```bash
npm install
cp .env.example .env
```

1. **ICS 주소**: [Google Calendar 설정](https://calendar.google.com/calendar/r/settings)
   → 왼쪽 "내 캘린더의 설정"에서 본인 캘린더 선택 → **캘린더 통합** 섹션
   → **"iCal 형식의 비공개 주소"** 복사 → `.env`의 `ICS_URL=`에 붙여넣기
2. **Chrome 확장**: `chrome://extensions` → 우상단 **개발자 모드** ON
   → **압축해제된 확장 프로그램을 로드** → 이 프로젝트의 `extension/` 폴더 선택
3. 실행:

```bash
npm start
```

관리 페이지(http://localhost:5959)가 자동으로 열립니다.

## 사용법

관리 페이지에서:

- **오늘 미팅 / 이번 주 미팅**: 미팅별로 [매번 / 이날만 / 안함] 클릭
  - **매번** — 캘린더에 뜨는 날마다 그날 시간에 자동 참여 (반복 미팅용)
  - **이날만** — 그 날짜 1회만 참여
- **이날 건너뛰기**: 등록된 미팅의 특정 회차만 제외
- **휴가 / 자리 비움**: 날짜 범위 지정 시 그 기간 전체 자동 참여 중지
- **지금 접속**: 즉시 열어서 동작 테스트
- 캘린더에 없는 미팅은 하단 **수동 추가**(날짜+시간+링크)로 등록

`npm start`를 켜둔 터미널이 실행 주체입니다 — 켜두면 날짜가 바뀌어도 계속 동작합니다.

## 설정 (.env)

| 키 | 기본값 | 설명 |
|---|---|---|
| `ICS_URL` | (필수) | 캘린더 iCal 비공개 주소 |
| `LEAD_SECONDS` | `60` | 미팅 시작 몇 초 전에 열지 |
| `AUTO_JOIN` | `true` | `false`면 참여 버튼은 누르지 않고 대기 화면까지만 |
| `PORT` | `5959` | 관리 페이지 포트 |

## 주의사항

- **iCal 비공개 주소는 비밀 URL입니다** — 링크만 알면 캘린더 내용을 볼 수 있으니
  유출하지 마세요. 유출 시 캘린더 설정에서 "재설정"으로 갱신할 수 있습니다.
  `.env`는 `.gitignore`에 포함되어 커밋되지 않습니다.
- macOS + Google Chrome 기준으로 만들어졌습니다 (`open -a "Google Chrome"`).
- Meet 화면 구조가 바뀌면 확장의 토글/참여 클릭이 실패할 수 있습니다.
  그 경우에도 탭은 열리므로 수동으로 참여하면 됩니다.
- 확장 코드를 수정하면 `chrome://extensions`에서 확장 새로고침(⟳)이 필요합니다.
